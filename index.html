Adaptive and Responsive Traffic Signal Control

Using Fog Computing and Reinforcement Learning

Designed and implemented an adaptive traffic signal control system using real-time traffic simulation data from SUMO integrated through TraCI. The system employs an Artificial Neural Network(ANN) trained using the Proximal Policy Optimization (PPO) reinforcement learning algorithm to dynamically optimize signal timings. Fog computing principles are applied to enable low-latency, decentralized decision-making, improving traffic flow efficiency and reducing congestion at intersections.
